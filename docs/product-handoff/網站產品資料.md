## B. 根據現有功能合理整理出的產品定位

### B1. 產品用途與主要使用者

這是一套把人員、日常事項及接續處理集中在同一個 Windows 工作環境的交班工具。工作人員接班時可查未完成事項，工作中追加處理進度，之後再依日期、狀態或關鍵字找回紀錄與匯出報表。

它處理的日常問題包括：交班訊息散在紙本／表格中、後續處理另記而難以對回原事件、跨班不容易看出哪些事項還沒完成。上述為功能推導的使用情境，不是客戶訪談或成效統計。

與一般 Excel 表格相比，系統已有事件與人員關聯、班次範圍、狀態及進度、查詢、角色限制與輸出流程；Excel 在此仍是報表交付格式。不能推導為所有照護業務或既有 Excel 流程都可取代。

合理目標使用者：

- 有固定值班／交班工作人員的小型住宿型單位；依據為班次、房床、人員事件與月曆流程。
- 需要追蹤住民日常事件的康復之家類型單位；依據為 DEMO 情境與住民欄位，並非真實客戶實績或醫療適用認證。
- 以單一 Windows 電腦工作、重視歷史查詢與報表留存的單位；依據為本機桌面架構與匯出功能。

「20～30 床」僅是需求中的例子；未找到容量驗證或正式規模定位，**待確認，不作已驗證規格**。

### B2. 可用的產品特色角度

- 本機優先：日常記錄與查詢在使用端電腦完成。
- 事件後續追蹤：追加處理進度附屬同一事件，方便跨班接續。
- 人員與事件一起查：由人員月曆、事件列表與明細回看紀錄。
- 熟悉的文件交接：依查詢範圍或單一事件匯出 Excel。
- 配合工作分工：角色與操作權限管理，仍受版本限制。
- 小型單位取向：聚焦交班、事件與查詢；「輕量化」只能描述用途集中，不代表有安裝容量、低記憶體或效能優勢測量。
- 可用安全措辭：「本機優先的資料處理方式，減少不必要的雲端傳輸需求，降低不必要的資安暴露面。」不能改成安全保證。

買斷授權方向：**待確認**。支援永久期限的核發能力，不等於已決定採買斷、終身更新或免維護費。

#### en-GB（200～350 words）

Small residential teams need to pass on more than a list of tasks. They also need to know what happened, what has already been done and which matters still need attention. This Windows desktop system brings those records into one workspace, helping staff carry everyday work from one shift to the next.

Resident events and general issues have their own records. Staff can add follow-up notes to an existing event, with the time and recording staff member attached, rather than creating an unrelated entry for every update. Event details and a timeline bring together the original record, subsequent progress and completion information. Date, status and keyword filters help users find earlier entries, while the resident calendar offers another way to review past events.

For internal documentation, users can export search results or an individual event to Excel. Resident information, room and bed settings, configurable fields and role-based permissions support the surrounding workflow. The actions available to each person depend on their role, the edition and the state of the record.

The system follows a local-first approach: its working database is held on the organisation’s computer, and core work can be carried out offline. This reduces the need to transfer routine records to a cloud service. Organisations still need to manage backups, exported files and access to the computer responsibly.

A Traditional Chinese demo with fictional data exists for exploring the workflow. Public availability and commercial licence terms remain to be confirmed. The English description does not imply an English-language interface.
