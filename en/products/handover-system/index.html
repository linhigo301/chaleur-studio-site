Handover &
Incident Tracking

Keep handovers, events and follow-up in one place.

For small residential teams with regular shifts and handovers. Record, find and follow up on everyday work on your own Windows computer.

Windows desktopLocal-firstWorks offline
Explore the workflow ↓About the demo

The screenshots below use fictional data and show ENGINEERING / DEMO editions. Available features depend on the edition and permissions.

01 / Start the shift

Start the shift.
Keep work moving.

Start by checking matters that need follow-up. Record new events and add progress during the shift, then find earlier records by date, status or keyword when you need them.

Copy the shift summary to the clipboard for easy sharing, while saving an Excel file at the same time for your records.

02 / Build the timeline

Build a timeline
for each service user

Create service-user events in the weekly handover view. Select an event to review observations and actions taken, and add follow-up progress to build a timeline of ongoing work.

03 / Find the context

Keep every person-related
event traceable

Find person-related events by date, handling status, tracking status, priority or keyword.

Select an event to review the original details, observations, actions taken and subsequent progress, without searching through separate shift records.

04 / Keep work connected

A new shift.
The same context.

Keep adding progress to equipment, environmental and other general issues. Each update stays with the original event, helping the next shift see where things stand.

05 / See the month

One service user.
A month in view.

The service-user calendar places events on the dates they happened, with monthly totals and event categories. Review what happened over a period of time or switch months to look back further.

Events

Search and records

  • Filtered search and previous records

Everyday administration

  • Resident, room and bed records
  • Staff accounts and role permissions
  • Edition-dependent backup and restore

Local-first.
Ready for offline work.

Core recording, search and licence verification run locally. The working database is held on the organisation’s computer, and everyday work does not require a continuous connection to a cloud service.

The organisation remains responsible for computer access, backups and exported files.
