小型機構交班系統

為小型機構整理日常交班，
讓每件事情的後續都有跡可循。

在自己的 Windows 電腦上，串起人員事件、處理進度與交班紀錄。

Windows 桌面Local-first · 離線作業工程／DEMO 功能展示
看看日常操作 ↓DEMO 與發行狀態
ENGINEERING / DEMO

工程版與 DEMO 功能展示，各圖分別標註展示版本。人物與事件均為虛構資料；實際功能依版本與權限而異。

目前為測試／驗收階段；正式商用發行與 DEMO 公開下載仍待確認。

從接班開始，
接續每件日常

將人員資料、日常事件與後續處理集中在同一個 Windows 工作環境。接班時查看待處理事項，工作中追加進度，再依日期、狀態或關鍵字找回紀錄。

適合有固定值班與交班需求、希望在單一電腦上整理事件的小型住宿型單位。住民事件與設備、環境等一般事項各自記錄，後續處理則附加於原事件。

01 / Find the context

找到事件，
也看見後續

依年月、處理狀態、追蹤狀態、優先級或關鍵字查找住民事件。在同一畫面回看事件內容、觀察、處遇與跨班追加的進度。

可依查詢結果或單一事件匯出 Excel，方便內部留存與交接。

02 / Keep work connected

換了班，
處理脈絡仍在

設備與環境事項也能接續記錄。把每次處理進度附加於同一事件，透過時間軸了解建立時間、後續處理與登錄人員。

下圖事件仍為未處理，呈現建立與兩次追加進度。時間軸不等同涵蓋所有編輯、刪除的不可變完整異動歷史；匯出按鈕是功能入口，並非報表成品或本次匯出驗證。

03 / See the month

以一位住民為起點，
回看整個月

住民月曆將事件放回日期中，搭配月份總件數與事件分類統計，方便回看一段時間的紀錄。點選日期可查看當日事件，也能切換月份查閱歷史。

04 / Share and keep

交班概要，
方便分享，也留存

產出值班概要後，可將文字複製至剪貼簿，方便貼到 LINE 或群組，並同步儲存 Excel 表格，作為內部交接與日後查閱的備存紀錄。

此圖為 DEMO 的本班概況。本班概況與登入稽核為 ENGINEERING／DEMO 專有，TRIAL／LICENSED 不提供；分享方式為手動複製、貼上。

日常工作所需

  • 人員資料與房床管理
  • 工作人員與角色權限
  • 交班週曆與月曆
  • 住民事件與一般事項
  • 跨班進度與狀態追蹤
  • 條件查詢與歷史回看
  • 查詢結果與事件 Excel 匯出
  • 版本允許的備份與還原

實際可操作項目受版本、角色與資料狀態限制。DEMO 不提供正式資料匯入及完整資料庫備份／還原；本班概況與登入稽核為 ENGINEERING／DEMO 專有。

本機優先，
支援離線作業

核心記錄、查詢與授權驗證採離線設計，工作資料庫保存在使用單位的電腦。本機優先的資料處理方式，減少不必要的雲端傳輸需求。

單位仍需妥善管理電腦存取權限、備份與匯出檔案。自行複製、匯出或使用同步資料夾，可能將資料移往其他位置。
