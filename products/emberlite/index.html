EMBERLITE

暗房放大機曝光控制系統

透過旋鈕與按鈕控制放大機曝光，接續化學計時，並保存每次放相的設定與記錄。

實體操作放相記錄本地網路 Web Console
看看實際畫面 ↓了解放相流程

01 / Print records

每一次放相，
留下條件與記錄

每次放相可搭配焦距、光圈、濾鏡、相紙種類與廠牌等資料，並以記錄保留工作條件。透過 Web Console 查閱既有設定，便於比對不同曝光條件，或回看先前的放相工作。

02 / Spectral data

從光譜資料，
配置數位燈具

搭配外部感測器及適用的數位燈具，可使用光譜採樣、基準校準、RGBW 擬合及實測校正，建立供數位曝光使用的設定。結果依連接設備與校正資料而定。

03 / Filter library

讓濾鏡配置，
接上曝光設定

在同一個濾鏡庫查看曝光係數、傳統與數位分類、啟用狀態及光譜對應。配合曝光補償與濾鏡係數計算，依選定的放相條件設定曝光時間。

從曝光，
接續放相流程

設定曝光條件

透過模式開關、旋鈕與按鈕設定時間、濾鏡及放相條件，再由實體主按鈕開始曝光，主機控制相應燈源的輸出與結束。

逐次完成試條

提供曝光補償、濾鏡係數計算與試條步進。每次曝光由操作者觸發，逐次比較不同條件。

接續四階段化學計時

啟用後，曝光完成會接續顯影、停顯、定影與水洗。各階段先等待操作者準備，再以按鍵開始倒數，並提供聲音提示與跳過操作。

回看與保存記錄

透過本地網路 Web Console 查閱放相記錄，也可匯出 CSV 留存。換槽及其他化學處理仍由操作者完成。

設備與連線

核心操作
曝光與化學計時在主機運作，以實體控制件操作。
本地網路
Web Console 透過本地 Wi-Fi，在瀏覽器中查閱記錄與配置資料。
數位燈具
光譜採樣與 RGBW 校正需搭配外部感測器及適用燈具。
